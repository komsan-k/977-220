# Introduction to Verilog/SystemVerilog

This four-topic sequence introduces digital hardware design using Verilog/SystemVerilog, progressing from logic fundamentals to combinational circuits, sequential circuits, and finite state machines (FSMs).

## Topic 1: Verilog/SystemVerilog-1 — Digital Logic Fundamentals

Learn how digital circuits represent and process binary information, and describe basic hardware using Verilog/SystemVerilog.

- Binary numbers, Boolean algebra, and logic gates.
- Modules, ports, signals, and basic operators.
- Continuous assignments and simple testbenches.

**Practice:** Implement and simulate basic logic gates.

## Topic 2: Verilog/SystemVerilog-2 — Combinational Design

Design circuits whose outputs depend only on their current inputs.

- Multiplexers, decoders, encoders, and arithmetic circuits.
- Combinational modeling using `assign` and `always_comb`.
- Complete assignments to prevent unintended latches.

**Practice:** Design and verify a multiplexer and a simple arithmetic logic unit (ALU).

## Topic 3: Verilog/SystemVerilog-3 — Sequential Design

Develop circuits that store information and update their state in response to clock events.

- Flip-flops, registers, counters, and shift registers.
- Clocked modeling using `always_ff` and nonblocking assignments.
- Synchronous and asynchronous resets.

**Practice:** Implement and simulate a counter with reset and enable controls.

## Topic 4: Verilog/SystemVerilog-4 — FSM Design

Combine combinational and sequential logic to implement controllers using finite state machines.

- State diagrams, transition tables, and state encoding.
- Moore and Mealy machines.
- State registers, next-state logic, and output logic.

**Practice:** Design and verify a sequence detector or traffic-light controller.
