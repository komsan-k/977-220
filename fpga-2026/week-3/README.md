# Introduction: FPGA Arithmetic Design Using Vivado

This laboratory series introduces basic arithmetic circuit design using Verilog and AMD Vivado. Students will learn how to design, simulate, and implement arithmetic circuits on an FPGA, starting with simple adders and progressing to multipliers and multiply-accumulate (MAC) circuits.

The laboratories consist of four topics:

- **Topic 9: Vivado-5 — System Hierarchy: Adder Design**  
  Design half adders, full adders, and a 4-bit ripple-carry adder using hierarchical Verilog modules.

- **Topic 10: Vivado-6 — System Hierarchy: Multiplier Design**  
  Design a binary multiplier using partial products and addition.

- **Topic 11: Vivado-7 — Fixed-Point Multipliers**  
  Implement signed fixed-point multiplication using simple combinational Verilog and learn about scaling and saturation.

- **Topic 12: Vivado-8 — Multiply-Accumulate (MAC) Design**  
  Combine multiplication and addition to build a sequential MAC circuit.

Through these laboratories, students will gain practical experience in Verilog programming, behavioral simulation, RTL schematic analysis, FPGA implementation, and hardware resource utilization.

The knowledge gained provides a foundation for advanced FPGA applications such as digital signal processing (DSP), embedded computing, and artificial intelligence accelerators.
