# FPGA Mini Projects: Stopwatch and One-Direction Intersection Traffic Controller

These two mini projects introduce students to the practical design and implementation of **digital systems using Verilog HDL and FPGA technology**. Students will apply fundamental concepts of sequential logic, counters, clock division, and finite state machines (FSMs) to develop functional hardware systems on the Nexys A7 FPGA board.

## Mini Project 1: Digital Stopwatch

The **Digital Stopwatch** project focuses on designing a time-measurement system using FPGA-based counters and control logic. Students will implement start, stop, and reset functions using push buttons and display elapsed time through a seven-segment display. This project strengthens students' understanding of clock division, synchronous counters, and digital display control.

**Learning outcome:** Design and implement a stopwatch using sequential logic and FPGA hardware.

## Mini Project 2: One-Direction Intersection Traffic Controller

The **One-Direction Intersection Traffic Controller** project focuses on designing an automated traffic-light control system using a finite state machine (FSM). Students will develop a controller that sequences through red, green, and yellow traffic-light states according to predefined timing intervals. LEDs on the FPGA board will represent the traffic signals.

**Learning outcome:** Design and implement an FSM-based traffic controller using state transitions, timing counters, and FPGA outputs.

## Expected Skills

Upon completing these mini projects, students will be able to:

1. Develop digital systems using Verilog HDL.
2. Apply counters, clock dividers, and FSMs to practical applications.
3. Verify system functionality using simulation and testbenches.
4. Implement and test digital designs on the Nexys A7 FPGA board.
